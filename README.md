# Bobcat Campaign Hub

Dealer-facing enrollment page for Flint's Bobcat co-op campaigns.

- `index.html`: the hub (campaigns, details pop-ups, checkout). Campaign data lives in the `CAMPAIGNS` list near the top of the script.
- `demos/`: the "See it in action" animations shown in each campaign's details, with the shared `player.js` controls.

Plain HTML, CSS and JavaScript. No build step. Enrollments post to a Zapier webhook.
